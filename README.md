## Cloudflare Pages

For a plain static site:

- Production branch: `main`
- Build command: leave empty if Cloudflare allows it, otherwise use `exit 0`
- Build output directory: `/` or the repository root, depending on the Pages UI

The `index.html` file must remain at the repository root.
